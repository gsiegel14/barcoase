# 🏥 Denver Health - QR Code Processor PWA

**Fully Offline QR Code Processing for Hospital Staff**

## 📱 Install on Your Phone (One-Time Setup)

### For iPhone:
1. Open **Safari** and go to: `https://gsiegel14.github.io/barcoase/`
2. Tap the **Share** button (⬆️)
3. Scroll down and tap **"Add to Home Screen"**
4. Tap **"Add"** - Done! 

### For Android:
1. Open **Chrome** and go to: `https://gsiegel14.github.io/barcoase/`
2. Look for **"Install App"** notification
3. Tap **"Install"** - Done!

## ✅ After Installation

- **No Internet Required** - Works completely offline
- **Find the app** on your home screen with Denver Health logo
- **All processing** happens on your device only
- **No data** is sent anywhere - fully private

## 🔧 How to Use

1. **Open the app** from your home screen
2. **Point camera** at QR code
3. **App processes** format: `WB##########|#######`
4. **Adds `.forexample`** automatically
5. **Copy result** to use elsewhere

## 🏥 For Hospital Staff

- Scans QR codes in Denver Health format

### ✅ What This App DOESN'T Do:
- Connect to hospital systems

- Share information with anyone

## 🆘 Need Help?

**App not installing?**
- Make sure you're using Chrome (Android) or Safari (iPhone)
- Try clearing browser cache
- Restart browser and try again

**QR codes not scanning?**
- Make sure camera permissions are enabled
- Try better lighting
- Hold phone steady over QR code

**App not working offline?**
- Make sure you opened it at least once while connected to internet
- Try closing and reopening the app
